Privacy Policy

Last Updated & Effective Date: October 31, 2026

1. Commitment to User Privacy

SEO Inspector ("we", "our", or "the extension") is a technical on-page diagnostics developer tool available for Microsoft Edge and Google Chrome. We believe developer utilities should prioritize transparency and privacy.

Key Guarantee: SEO Inspector does not operate remote analytics servers, tracking infrastructure, or developer-controlled backends. Active page diagnostics and DOM inspections run directly inside your local browser memory without transmitting your inspected URLs, HTML page source, or audit findings to the developer.

2. Data Collection and Processing

  • Zero Personal Data: We do not ask for or collect names, email addresses, IP addresses, browsing histories, or hardware identifiers. The developer operates no remote telemetry or analytics backend.
  • Active-Page DOM Inspection: When you click the extension icon to run a diagnostic audit, the script examines the active tab's Document Object Model (DOM) and browser Navigation Timing data strictly within local browser memory.
  • Ephemeral Calculations: Word counts, heading hierarchies, link targets, and Schema.org entities exist only in memory while the popup is open and are discarded immediately upon closure.

3. Browser Permissions & Storage Architecture

To perform in-depth technical audits, the extension requests the following permissions declared in manifest.json:

activeTab
Grants temporary permission to interact with and inspect the Document Object Model and Navigation Timing APIs of the currently focused browser tab only when the user explicitly clicks the extension popup. It does not monitor background browsing or unrelated tabs.
scripting
Used to inject the lightweight client-side DOM extraction script (extractor.js) into the active tab to read headings, canonical links, robots tags, and Schema.org scripts directly within the page context.
storage

Used to persist user settings and audit configuration across browser storage APIs:

  • User Preferences (chrome.storage.sync): Custom audit thresholds (e.g. title/description lengths, image warning thresholds, text-to-code ratio), report branding (auditor name), and display preferences are stored using the browser's synchronization storage. When browser account synchronization is enabled by the user in Microsoft Edge or Google Chrome, these settings may synchronize across your logged-in browser instances via your browser account provider (Microsoft or Google). Page contents, audit results, and browsing history are never stored or synchronized.
  • Local Storage & Legacy API Key Migration (chrome.storage.local): Starting with extension version 1.0.1, any legacy Google PageSpeed Insights API key previously entered by the user is migrated to local extension storage (chrome.storage.local) and excluded from future sync payloads to ensure it remains stored locally on that device. While this migration strips the key from future synchronization writes on that device, it does not guarantee that historical synced copies stored by the browser provider across other unsynchronized devices have been erased everywhere. Google PageSpeed API integration is inactive in this version, and key entry is disabled.

4. Third-Party Disclosure, Telemetry & External Links

No Developer Telemetry: We do not operate remote tracking servers, sell user data, or harvest analytics. No Google Analytics, telemetry beacons, or third-party ad networks are included in the extension build package.

Optional External Audit Links (Google PageSpeed Insights & Schema.org): The extension includes optional external inspection buttons, such as "Open in Google PageSpeed Insights" in the PageSpeed tab, and external validator links in the Structured Data tab. Clicking these links opens external third-party testing services in a new tab (https://pagespeed.web.dev/analysis?url=..., Google Rich Results Test, or Schema.org Validator). If you choose to click these links, the active page URL is shared with the external service in the query string of the opened tab, governed by Google's or Schema.org's respective privacy policies. The extension never automatically opens external links or transmits URLs in the background.

5. Data Export Features

When you utilize the "Export Markdown Report" or "Export JSON Audit" buttons, the file is generated entirely within your browser client using standard Blob URLs. No data is routed through external web APIs.

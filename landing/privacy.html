Privacy Policy

Last Updated & Effective Date: September 25, 2026

1. Commitment to User Privacy

SEO Inspector ("we", "our", or "the extension") is a technical on-page diagnostics developer tool available for Microsoft Edge and Google Chrome. We believe that developer utilities should prioritize privacy above all else.

Key Guarantee: SEO Inspector executes 100% locally on your machine inside your browser. We do not operate remote tracking servers, do not harvest analytics, and never transmit your inspected URLs, page source, or diagnostics to any cloud infrastructure.

2. Data Collection and Processing

  • Zero Personal Data: We do not ask for or collect names, email addresses, IP addresses, browsing histories, or hardware identifiers.
  • Local DOM Inspection: When you click the extension icon to run a diagnostic audit, the script examines the active tab's Document Object Model (DOM) strictly within local browser memory.
  • Ephemeral Calculations: Word counts, heading tree depths, link targets, and Schema.org entities exist only while the popup is open and are discarded immediately upon closure.

3. Browser Permissions Explained

To perform in-depth technical audits, the extension requests the following minimum viable permissions declared in manifest.json:

activeTab
Grants temporary permission to interact with the currently focused browser tab only when the user explicitly clicks the extension popup. It does not allow background monitoring of unrelated tabs.
scripting
Used to inject the lightweight DOM extraction script (extractor.js) into the active tab to read headings, canonical links, robots tags, and Schema.org scripts.
storage
Used exclusively to persist user UI preferences locally (such as active tab view or theme state). No diagnostic data or website contents are ever written to persistent remote storage.

4. Third-Party Disclosure & Telemetry

We do not sell, rent, trade, or transfer any user information to outside parties. No Google Analytics, telemetry beacons, or third-party ad networks are included in the extension build package.

5. Data Export Features

When you utilize the "Export Markdown Report" or "Export JSON Audit" buttons, the file is generated entirely within your browser client using standard Blob URLs. No data is routed through external web APIs.
